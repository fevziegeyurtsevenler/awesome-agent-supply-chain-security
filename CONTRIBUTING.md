# Contributing

Thanks for helping build the reference list for agent supply-chain security.

## Guidelines

- One entry per line: `- [name](https://link) - Short description ending with a period.`
- Only add resources that are **genuinely useful, accurate and maintained**.
- Put each entry in the most fitting section; keep alphabetical order where practical.
- No affiliate links, no low-effort or self-promotional spam.
- Prefer primary sources (the tool's repo, the paper, the vendor's own writeup).
- New **attack techniques**, **empirical studies** and **defenses** are the most valuable additions.

## How

1. Fork and create a branch.
2. Add your entry and, if useful, a one-line rationale in the PR description.
3. Make sure links resolve and descriptions are neutral and factual.

## Reporting malicious extensions

If you're linking evidence of a malicious real-world extension, report it to the
hosting marketplace first and do not link live payloads. Point to the analysis,
not the weapon.
